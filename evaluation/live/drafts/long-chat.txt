## 7. You

can you explain how pathlib glob works with hidden files

## 8. Assistant

`Path.glob('*')` skips nothing by name: on Linux and macOS it includes dotfiles, so `.DS_Store` would be moved. I'd skip names starting with a dot unless you pass --include-hidden. On Windows, hidden is an attribute, not a name, so that check needs `os.stat(...).st_file_attributes`. This matters because macOS writes .DS_Store into every folder you open in Finder, and moving it is harmless but noisy, while on Windows desktop.ini files control folder icons and moving them would change how your folders look. Most cleaning tools skip both by default for that reason, and add a flag for people who really want them moved.

## 9. You

what about symlinks

## 10. Assistant

`is_file()` follows symlinks, so a link to a file in another folder would be moved as a link (the target stays put). That's safe, but surprising. I'd skip symlinks by default (`f.is_symlink()`) and log them. Broken symlinks return False for is_file(), so they're skipped already. If you later add a --follow-links flag, be careful: moving the target instead of the link would take files out of the folders they belong to, which would quietly break your never-delete promise in spirit, even though nothing is deleted.
