# Handoff privacy policy draft

**Date:** 2026-10-20. This draft must be published at a stable public URL before a Chrome Web Store submission.

Handoff reads rendered conversation text only on the supported AI chat sites named in its manifest. It uses that text to maintain a local project brief, show a reviewable handoff draft, and estimate usage from visible page notices and local history. Briefs, settings, and diagnostics are stored in Chrome's local extension storage on the user's device. Users can export projects or delete all Handoff data from the options page.

Handoff does not operate an account, analytics, or synchronization server. It does not read cookies, passwords, or provider session credentials. It does not submit messages. The user chooses a destination and presses Send there. The extension can optionally open a destination tab and insert text into its editor as a draft.

Handoff may recognize common key and personal-data patterns before rendering a draft, but automated detection can miss sensitive data. Users should inspect and edit the draft. Copying a draft or sending it in a provider's chat is governed by that provider's own policies.

The source includes an opt-in, hash-verified remote selector updater, but the current interface does not enable it. If introduced later, the privacy policy and permission disclosures must be updated with the exact endpoint and data transferred.
